Insertion details


    
Uses the notebook's six transforms with manipulator +X/+Y/+Z
      mapped to probe +X/+Z/-Y. The move-to-surface translation uses Surface Z relative to Bregma Z,
      then recording depth advances along local probe -Y.
      Spin therefore rotates the offset as well as the probe. The two local translations also cancel depth
      in the final tip position if the manipulator offset is held fixed.
      Posterior-positive Arc AP uses Arc AP + head angle; anterior-positive uses -(Arc AP - head angle).
      The default head-angle correction is +14 degrees.

    
Brain/region placement uses the coordinate builder's approximate CCF-to-bregma mapping,
      not individual-animal registration. Target meshes show intended areas, not verified hits.
      A trajectory is shown only for a confirmed insertion with complete numeric data.

Usage

    
Run python code/insertion_tracking.py, then
      python -m http.server 8000 --bind 127.0.0.1 from the repository root.
      Open http://localhost:8000/code/insertion_viewer.html.
      Or open this page directly and choose the converted CSV above.
      Network access is required for Three.js and atlas meshes; CSV data stays in your browser.

  

  

    
Drag: orbit | Shift/right-drag: pan | Scroll: zoom

      Red: +R | Green: +A | Blue: +S | Origin: bregma

      Orange: selected probe | Pink: surface-to-tip | Purple: target area

      Probe axes: red X, green +Y (tip to base; insertion is -Y), blue Z
